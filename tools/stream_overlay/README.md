# All-in-one Stream Overlay

Замість 23 окремих Link-джерел — **один** HTML-оверлей із 4 віджетами + плашкою цілі.

## Використання

1. Запустіть `START_OVERLAY.bat` (вікно має бути відкрите під час стріму).
2. У TikTok LIVE Studio: **Додати джерело → Посилання**.
3. Вставте: `http://127.0.0.1:8765/overlay.html`
4. Розтягніть джерело на весь кадр.

## Що всередині

| Елемент | Позиція | Джерело |
|---|---|---|
| Activity Feed (фоловери, лайки, дари, коментарі) | вгорі зліва | TikFinity iframe |
| Top Gifter (топ дарителів) | вгорі справа | TikFinity iframe |
| Timer (час стріму) | внизу зліва | TikFinity iframe |
| Viewer Count (глядачі) | внизу справа | TikFinity iframe |
| Плашка «$100 GOAL — Реліз в App Store» | вгорі по центру | статичний HTML |

## Важливо

- **Живі віджети потребують активного стріму + підключеного TikFinity.**
  Поки стрім не запущено, iframe можуть бути порожніми — це нормально.
- **Прогрес цілі $100 не оновлюється автоматично** в цій плашці.
  Для живого прогресу додайте окремо вбудований віджет LIVE Studio:
  **Додати джерело → Ціль** → назва `Реліз в App Store — $100`, сума `100`.
- Якщо TikFinity раптом заборонить iframe — замініть оверлей на окремі
  Link-джерела з URL з `docs/TIKFINITY_WIDGETS.md`.

## Кастомізація

Positions і розміри — у блоці `/* ... */` CSS у `overlay.html` (`#feed`, `#top`,
`#timer`, `#viewers`, `#goal`). Щоб додати ще віджет — скопіюйте блок `<div class="widget">`
з новим `src` і задайте йому координати.
