# Небесний горизонт — FPV-симулятор дрона

FPV-симулятор бойового/цивільного дрона на **Godot 4.6**. Містить процедурні
карти, режими тренування, гонки, бойові місії, спецоперації та вільний політ.

> Поточна цільова платформа: **iOS** (unsigned IPA через GitHub Actions,
> Sideloadly + безкоштовний Apple ID). iPhone 14 + ELRS WiFi.
> Деталі: `docs/IOS_GITHUB_BUILD.md`.

## Запуск

- Windows 10/11, 64-bit.
- Мінімум: Intel UHD Graphics (перевірено на i3-1115G4), 8 ГБ RAM.
- Рекомендовано: дискретна GPU, геймпад/радіоапаратура з 4 осями.

Запустіть EXE. Меню → вибір карти/режиму → брифінг → політ.
Налаштування графіки відкриваються з головного меню або в польоті клавішею **F3**
(циклічно змінює пресет).

## Керування (клавіатура)

| Клавіша | Дія |
|---|---|
| `Space` | Arm / зліт |
| `Esc` | Пауза (дрон жорстко заморожується) |
| `F1` | Діагностика / FPS |
| `F2` | **Скріншот** (кадр заморожується, файл у `screenshots/` біля EXE) |
| `F3` | Перемкнути пресет графіки |
| `F4` | Режим зору (звичайний / FLIR) |
| `F5` | Погода |
| `T` | Тепловізор (для бомбардувальника) |
| `G` | Скинути підвіс (бомбардувальник / дроп-дрон) |
| `F` | Активувати/підірвати підвіс (камікадзе) |
| `H` | Допомога / підказки |

Для польоту потрібна радіоапаратура/геймпад або призначені осі. Калібрування
осей — у меню налаштувань. Дрон стоїть на стартовому майданчику до Arm.

## Карти та режими

- **Industrial**, **Village**, **Steppe**, **Wetlands** — фронтові процедурні
  карти з hero-ангаром, окопами, технікою, піхотою, полями та лісосмугами.
- **City** — модульний бетонний район 1.2 км із наскрізними отворами у
  будинках (низькі, середні та високі).
- **Course** — траса/полігон із воротами та кільцями.
- Режими: Training, Combat, Speed, Tutorial (льотна школа), Chaos,
  спецоперації (розвідка, супровід, нічний удар, РЕБ тощо).

## Графічні пресети

У меню рівно **3 основні профілі** (зайві прибрані):

1. **Низька** — максимальний FPS: FSR 40–72%, легка рослинність, тіні 90 м.
2. **Середня** — баланс: FSR 55–85%, щільна трава, тіні 120 м.
3. **Висока** — нативна роздільність, SSAO, м'які тіні 180 м.

Пресет можна змінювати на льоту через `F3`. На слабких інтегрованих GPU гра
автоматично стартує в **Середня** (Intel UHD) або **Низька** (старіші Intel HD),
щоб зберегти текстури й нормальний вигляд світу. Старі конфіги з 7 пресетів
автоматично переводяться: UFDS → Висока, решта → Низька.

## iOS + ELRS WiFi

- Збірка **unsigned IPA** автоматично в GitHub Actions (macOS-раннер):
  `.github/workflows/ios.yml`.
- Встановлення на iPhone 14 (Lightning) через **AltStore + LocalDevVPN** з
  безкоштовним Apple ID; підпис діє 7 днів.
- Пульт Radiomaster Pocket підключається **по Wi-Fi ELRS** (протокол
  «Velocidrone Mobile»): iPhone → `ExpressLRS TX`, у грі `ELRS: ПОТІК`.
- Канали: CH1 roll, CH2 pitch, CH3 throttle, CH4 yaw, CH5 arm, CH6 режими,
  CH7 відео. На екрані є кнопка **АРМ**.
- **Сенсорне керування:** два віртуальні стіки (лівий — газ/рискання,
  правий — тангаж/крен), кнопка **ВВІД: СЕНСОР/ПУЛЬТ** і **АРМ**. Верхня
  панель: **МЕНЮ**, **РЕЖИМ**, **НАЛАШТ.**, **СКИД**, **ЗАСТ.**, **РЕСЕТ**,
  **ВІДЕО**. **НАЛАШТ.** — живі CH1–16, призначення каналів ARM/режимів/відео
  та інверсія крену для ELRS/сенсора. Працює без пульта; на Windows
  тестується з `TOUCH_CONTROLS=1`.
- Старі екрани **КЕРУВАННЯ** та **КАЛІБРУВАННЯ** адаптовані під телефон:
  у списку джерел є **ELRS WiFi** і **Сенсорні стіки**, майстер калібрування
  проходить сенсорними стіками або Pocket, калібрування ELRS зберігається
  й застосовується до польоту. У **КНОПКИ ТА ПЕРЕМИКАЧІ** кнопка **Авто** +
  тумблер Pocket (CH5–CH16) призначає будь-яку дію — скид, застосування БЧ,
  ресет, ARM, режими, паузу. Відкриваються з головного меню або паузи
  (Налаштування → КЕРУВАННЯ / КАЛІБРУВАННЯ).
- Покроково: `docs/IOS_GITHUB_BUILD.md`.

## Що нового у v11

- **Спавн більше не всередині геометрії.** Дрон ставиться на поверхню
  `StaticBody3D` променем/капсулою з безпечним відступом 0.5 м, з нульовими
  швидкостями; перевіряється перекриття з будівлями, деревами, парканами.
  Steppe hero-ангар перенесений на чисту ділянку, щоб не накладатися на ферму.
- **Жодних висячих об’єктів.** Дороги/пропи/ферми прив’язані до висоти
  рельєфу, всі статичні об’єкти заглиблені на 0.2–0.5 м. Pre-batch QA-сканер
  `qa_floating_scanner.gd` перевіряє 4 карти: **0 floating**.
- **PBR-матеріали для успадкованих GLB.** `glb_material_utils.gd` +
  `EditorScenePostImport`-хук оновлюють 17 моделей дронів (albedo/roughness/
  normal/AO), без плоских матеріалів.
- **Логіка ролей дронів.** Бомбардувальники (BABA YAGA) і дроп-дрони
  (GRIM-7M) скидають підвіс як `RigidBody3D` з балістикою; детонація — лише
  при `body_entered`. Камікадзе (FURIA, LELEKA) мають вбудовану БЧ: контакт
  вище 7 м/с при `armed` + `_was_airborne` дає миттєвий вибух (зона, імпульс,
  GPUParticles3D, кратер/декаль). Торкання трави на спавні не детонує.
- **AVATA 2 знову вибирається** у великому ангарі: цивільні/розвідувальні
  дрони не блокуються, а переводять виліт у вільний політ (TRAINING).
- **Унікальні POI на кожну карту:** водонапірна вежа (Industrial),
  трансформаторна підстанція (Village), згоріла бронетехніка (Steppe),
  спостережна вежа (Wetlands).
- **Миттєве скидання підвісу.** Кнопка/тумблер реагують на фронт осі без
  таймерів; `Payload` прокидається одразу (`sleeping = false`), HUD
  синхронізується, повторне скидання заблоковане.
- **Тактичний one-pass левел-дизайн:** `scripts/util/map_enricher.gd` додає
  по 2 FPV-сети на карту (слаломні ворота, контейнерний каньйон, труба,
  трубопровід, арка, бункер) + 70/150/240 об’єктів польового реквізиту через
  MultiMesh. Деталі — `docs/AUDIT_2026-11-08.md`, розділ 7b.

## Що виправлено у v10 (історія)

- Спавн на фронтових картах винесений **назовні hero-ангара**, на чистий
  бетонний майданчик; трава/реквізит/дроти прибрані із зони зльоту.
- Прибраний солідний «стовп світла» (god-ray) у центрі ангара.
- Дороги більше не проходять крізь підлогу ангара; додана чиста бетонна
  підлога, дороги об'єднані в один draw call.
- Пауза жорстко заморожує дрон і **відновлює попередній стан** (дрон на
  старті не падає після виходу з паузи). `F2` робить нерухомий скріншот.
- Звук двигуна йде з **одного** джерела; петлі двигуна й меню оброблені від
  клацань на стику (без «пульсації»).
- Масштаб дерев збільшений до зрілого розміру (9–17 м крони), єдиний
  vegetation-library на всіх картах.
- City: низькі + середні + високі отвори у 27 будинках; бетонні текстури на
  фасадах/дахах; газони отримали трав'яну PBR-текстуру.
- Industrial: контейнери отримали сталеву текстуру; великі плоскі поверхні —
  бетонну.
- Доданий прогрів сцени під час loading screen, щоб прибрати стартовий
  фриз 0.5–1.1 с.
- Виправлені попередження `det == 0` при завантаженні Village.
- Спецоперації: HUD тепер показує **ЗОНИ / СУПРОВІД / ПІЛОТ / ВАНТАЖ /
  ЦІЛІ** замість безглуздого `0/0`; TAC-05 (USV «Магура») більше не спавнить
  бетонний майданчик на воді.
- Прибрано головне джерело ривків: трава більше **не перебудовується при
  русі вгору/вниз**; локальна сітка висот + один buffer upload; фіксований
  патерн трави генерується один раз, а перебудова розтягується на кілька
  кадрів (стара трава лишається видимою). Атмосферні вибухи переведені в
  аудіо, а їхні звуки й шейдери прогріваються під loading screen. Замір
  25-с прольоту MEDIUM: **100.3 FPS, p99 18.4 мс, 0 кадрів >50 мс**
  (раніше 76 кадрів >50 мс і фриз 0.4 с на першому вибуху).
- Сільські ферми на околиці більше не висять і не тонуть: висота береться з
  **реальної сітки terrain** (білінійна інтерполяція 8-м комірок), а не з
  аналітичного шуму; фундамент закриває схил.
- **Відкриті верхівки + нижні отвори (усі карти з вежами)**: у градирень,
  димарів, заводських труб, силосів і водонапірних баків більше немає
  суцільної кришки. Верхній отвір — щоб залетіти, **два протилежні нижні
  отвори** — щоб вилетіти. Зокрема: 3 високі труби долини (38/35/24 м),
  заводський димар Industrial (перенесений на чисте місце, щоб нижні отвори
  не впиралися в ангар), градирня/димар/силоси Industrial, димарі
  Village/Steppe/Wetlands. Колізія — trimesh з backface, отвори прохідні.
- Тонка труба Village більше не перетинається з силосами: димар перенесений
  на чисту ділянку двору, стінка потовщена до 0.6 м, верхній обідок став
  масивним. Прибрано 3 вентиляційні ковпаки, 71 тонку фасадну стійку та
  4 верхні панелі, які висіли в повітрі; прибрані прожекторні щогли двору.
- Проліт крізь стіни/дахи: колізія тепер будується для **кожної поверхні**
  GLB-меша (раніше багатоповерхові меші давали лише одну поверхню), з
  `backface_collision` для тонких стін. Це стосується будинків Village,
  ангара, заводу, міста й тераси.
- Градирня: два великі наскрізні отвори 2–31 м; силоси: по два отвори
  4–12 м з trimesh-колізією; у високого димаря factory_complex вирізана
  центральна шахта з відкритим верхом.
- Посадка: 5 променів (центр + кути) знаходять підлогу, дах, контейнер або
  схил до 70°; дрон м'яко сідає, автоматично дисармиться й фіксується, щоб не
  зісковзувати. Армування знову розморожує його. Перевірено на площині та
  схилі 20°.
- У меню лишилися **3 графічні пресети** — Низька / Середня / Висока; старі
  конфіги мігрують автоматично.

## Структура

- `sceneries/` — сцени карт і режимів.
- `scripts/util/frontline_terrain.gd` — процедурний терен, ангари, дороги,
  дерева, батчинг, матеріали.
- `scripts/util/quality_manager.gd` — пресети графіки.
- `drone/` — фізика, мотори, камера, керування.
- `combat/` — цілі, піхота, техніка, місії.
- `test/` — headless QA-тести та аудити.
- `tools/` — Blender/Python-скрипти підготовки асетів.
- `qa_shots/` — службові скріншоти перевірок.
- `docs/AUDIT_2026-11-08.md` — детальний діагноз скріншотів, зміни
  spawn/доріг/POI та результати QA.
- `CREDITS.md` — автори та ліцензії. `LICENSE` — GPLv3.

## Відомі обмеження

- Це робочий прототип, не фінальний комерційний продукт.

- Повний художній пас (AO, єдиний color grade, унікальні текстури кожного

- Ліцензії успадкованих асетів треба звірити перед публічним релізом
