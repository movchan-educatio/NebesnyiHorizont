# План компонування меню

## 1. Принцип

Дві окремі оболонки:

- **PC** — поточний стартовий екран із відео та поточні меню. Нічого не
  перебудовуємо, лише лишаємо сумісність.
- **Mobile** — нова оболонка в стилі референсу: темно-зелені панелі, округлі
  картки, бурштинові секції, великі кнопки, safe-margins, видимі скроли.

Функції не вигадуємо. Кожна кнопка або відкриває наявний екран, або змінює
наявний стан гри.

## 2. Карта навігації

```
StartScreen (PC)
└─ MainMenu (PC)

StartScreen (iOS) ──► MOBILE HOME
                        ├─ ГРАТИ ─────────► ОПЕРАЦІЇ
                        │                    ├─ 4 карти
                        │                    ├─ 5 режимів
                        │                    ├─ 6 місій (тільки бойовий)
                        │                    └─ ЗАПУСК
                        ├─ КЕРУВАННЯ ──────► ControlsScreen
                        │                    └─ КАЛІБРУВАННЯ ──► CalibrationScreen
                        ├─ РЕЙТИ ──────────► QuadSettingsMenu
                        ├─ АНГАР ──────────► DroneSelectScreen
                        ├─ НАЛАШТУВАННЯ ───► OptionsMenu
                        │                    ├─ КЕРУВАННЯ
                        │                    ├─ КАЛІБРУВАННЯ
                        │                    ├─ ГРАФІКА
                        │                    ├─ ЗВУК / HUD
                        │                    ├─ ДОВІДКА
                        │                    └─ НАЗАД
                        └─ ДОВІДКА ────────► HelpScreen
```

Усі внутрішні екрани на телефоні мають кнопку **НАЗАД**, яка повертає в
Mobile Home (на ПК — у MainMenu, як зараз).

## 3. Спільний мобільний каркас

- Фон: розмитий брендовий дрон + темно-зелений scrim.
- Верх: великий **центрований** `НЕБЕСНИЙ ГОРИЗОНТ` + `БОЙОВИЙ FPV
  СИМУЛЯТОР · МОБІЛЬНИЙ ТЕРМІНАЛ` під ним.
- Праворуч у куті: живі чипи `ELRS: …` та `ВХІД: …`.
- Низ: версія та `ГРАВЕЦЬ: …`.
- Безпечні поля: 6% від меншої сторони екрана (мін. 32 px) плюс симетричний
  запас під виріз камери. Жодні повзунки чи кнопки не торкаються краю.
- Орієнтація: `sensor landscape` — гра повертається за пристроєм. Симетричний
  notch-запас лишає інтерфейс безпечним і після повороту на 180°.
- Скрол: видимий 14 px повзунок, `follow_focus`, прокрутка пальцем і колесом.
  У списках, що обрізаються, нижній край м’яко затемнюється (fade).
- Кнопки: мінімум 58 px висоти; таби режимів — 84 px; місії — 62 px.
- Заголовки: 28–40 px; основний текст 15–22 px; підписи — не менше 11 px.

## 4. Екрани

### 4.1 Mobile Home

- Ліва колонка ~34%: великі `ГРАТИ`, `КЕРУВАННЯ`, `РЕЙТИ`, `АНГАР`,
  `НАЛАШТУВАННЯ`, `ДОВІДКА`.
- Праворуч — hero-картка з брендовим дроном і кнопкою `ПОЧАТИ ОПЕРАЦІЮ`.
- Знизу — реальний перемикач `СТРІМ-РЕЖИМ` і `ПОВНЕ МЕНЮ` (старий MainMenu).
- Статуси ELRS/входу — живі, з існуючих автозавантажень.

### 4.2 Операції

- Шапка `ОПЕРАЦІЇ` + поточний вибір.
- 4 картки карт у ряд: реальні top-down recon-скріншоти, назви **Степ**,
  **Село**, **Промзона**, **Болота**, складність.
- Нижче — сегментовані таби режимів: `ТРЕНУВАННЯ`, `БОЙОВИЙ`,
  `ШВИДКІСНИЙ`, `ТУТОРІАЛ`, `ХАОС`.
- Праворуч — велика кнопка `ЗАПУСК`.
- Для бойового режиму — ряд із 6 реальних місій кампанії; заблоковані
  показуються приглушено. Це ті самі `Global.is_mission_unlocked` і
  `Global.campaign_unlocked_mission`.
- Ніяких магазинів, ghost, racing line чи photo mode.

### 4.3 Керування

- Телефон: один вертикальний скрол.
  1. Компактний 3D-монітор пульта TX12 (видно рух стіків).
  2. `СІТКА ОСЕЙ` — 8 осей.
  3. `КАНАЛИ ПУЛЬТА` — газ, рискання, тангаж, крен.
  4. `ELRS / СЕНСОР` — джерело, інверсія крену, калібрування.
  5. `ПРИВ'ЯЗКИ` / `КНОПКИ ТА ПЕРЕМИКАЧІ`.
- Планшет/ПК-ширина: три колонки, як зараз.
- Знизу фіксована кнопка `НАЗАД`.
- 3D-пульт не ховаємо: він компактний, але стіки рухаються.

### 4.4 Калібрування

- Телефон: зліва компактний 3D-пульт + двовісьовий gimbal-монітор,
  справа — крок майстра й діагностика.
- Кнопки `ПЕРЕВІРИТИ`, `ПОПЕРЕДНІЙ КРОК`, `СПОЧАТКУ`, `НАЗАД` — у
  доступній нижній зоні; за потреби скрол.
- Планшет/ПК: повний триколонковий майстер.
- Використовується той самий `CalibrationScreen`, без нових кроків.

### 4.5 Рейти

- Ліва колонка: кут камери, суха маса, маса акумулятора.
- Права: пресети `СТАБІЛЬНИЙ / СПОРТ / ГОНКА / КІНО`, повзунки rate/expo
  по осях, графік, TTX.
- Знизу: `СКИНУТИ ПАРАМЕТРИ БОРТУ`, `СКИНУТИ РЕЙТИ`, `НАЗАД`.
- Обидві колонки скроляться незалежно; повзунки не біля краю.

### 4.6 Ангар

- Дві колонки: зліва список дронів (скрол), справа великий 3D-перегляд.
- Підписи списку та текст під прев'ю — менші; сам 3D-перегляд — більший
  (40–50% висоти екрана).
- Кнопка `ОБРАТИ` в рядку, `ОБРАНО ✓` під прев'ю, `НАЗАД` знизу.
- Тільки наявні дрони з `DroneCatalog`; без магазину й фейкових деталей.

### 4.7 Налаштування

- Центрована картка з реальними пунктами:
  `КЕРУВАННЯ`, `КАЛІБРУВАННЯ СТІКІВ`, `ГРАФІКА`, `ЗВУК, HUD І СИМУЛЯЦІЯ`,
  `ДОВІДКА Й КЕРУВАННЯ`, `МОБІЛЬНИЙ ІНТЕРФЕЙС`, `НАЗАД`.
- Відкриває наявні екрани; MobileMenu не дублює їхні налаштування.

### 4.8 Графіка

- 3 реальні пресети `НИЗЬКА / СЕРЕДНЯ / ВИСОКА`.
- Скрол-список: рівень графіки, FPV-канал, режим вікна, масштаб,
  MSAA, анізотропія, тіні, риб'яче око, роздільність/MSAA об'єктива,
  VSync, ліміт FPS.
- Знизу фіксовано `СКИНУТИ ГРАФІКУ` та `НАЗАД`.
- Усе — наявні `Graphics`-налаштування.

### 4.9 Звук / HUD

- Мобільна версія — три великі картки замість старої двоколонкової форми:
  **ЗВУК** (гучність, звук відео), **ТРЕНАЖЕР / СИМУЛЯЦІЯ** (профіль
  `АРКАДА / БОЙОВИЙ РЕАЛІЗМ`, обмеження зв'язку, зони РЕБ, вітер,
  Angle-режим, нескінченна батарея), **ІНТЕРФЕЙС (HUD)** (FPS і HUD-елементи).
- Скрол із м’яким нижнім fade; знизу фіксовано `СКИНУТИ HUD`, `НАЗАД`.
- ПК-версія цього екрана не змінюється.

### 4.10 Довідка

- На телефоні перший блок — **СЕНСОРНИЙ ЕКРАН**: лівий/правий стік, АРМ,
  РЕЖИМ, круглий СКИД, ВІДЕО, МЕНЮ/РЕСЕТ, ВВІД, поворот екрана й виріз.
- Далі — дві колонки наявного тексту: керування/бойові функції та
  кампанія/фази.
- Скрол; знизу `РОЗПОЧАТИ КУРС ПІЛОТА` і `НАЗАД`.
- Жодних нових інструкцій чи функцій.

## 5. Скроли

- Скрол там, де контент не вміщується: Керування, Калібрування, Рейти,
  Ангар-список, Графіка, Звук/HUD, Довідка.
- Повзунок видимий, темно-зелений, 14 px; колесо миші, палець, клавіатура.
- Нижні кнопки дій не перекривають контент: або фіксований футер, або
  контент має нижній відступ.
- На вузьких екранах нічого не обрізається без можливості доскролити.

## 6. PC

- `StartScreen` з відео, `MainMenu` і всі старі меню — без змін.
- Мобільна тема вмикається лише на iOS/Android (або `MOBILE_UI=1` для QA).
- MobileMenu можна відкрити на ПК через `НАЛАШТУВАННЯ → МОБІЛЬНИЙ ІНТЕРФЕЙС`
  для перегляду, але він не замінює PC-меню.

## 7. Порядок робіт

1. Зафіксувати цей план.
2. Довести мобільну тему для наявних екранів (кольори, панелі, кнопки, скроли).
3. Довести компонування кожного екрана під телефон/планшет.
4. Перевірити всі переходи й повзунки.
5. Скріншоти 1920×885, 1280×590, 1024×768, 2340×1080.
6. Після затвердження — збірка IPA.
