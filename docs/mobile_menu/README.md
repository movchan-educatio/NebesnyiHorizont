# Мобільний інтерфейс — телефонне меню

Файли: `GUI/mobile/MobileMenu.tscn`, `GUI/mobile/MobileMenu.gd`.

Меню побудоване лише з реальних систем гри. Воно не містить магазину,
платних деталей, ghost-дрона, racing line, photo mode чи інших вигаданих
функцій. Усі кнопки або змінюють реальний стан гри, або відкривають наявний
екран.

Мобільна тема застосована до всіх наявних екранів: темно-зелені картки,
бурштинові підписи секцій, великі кнопки, видимі скроли. ПК-версія лишається
в старому стилі — мобільна тема вмикається лише на iOS/Android або через
`MOBILE_UI=1` для QA.

На головній назва **НЕБЕСНИЙ ГОРИЗОНТ** винесена великим центрованим
заголовком; живі чипи ELRS/входу — у правому куті. Усі підписи й кнопки
тримаються в безпечних полях, а не біля краю екрана.

Орієнтація — **sensor landscape**: гра повертається за пристроєм, а
`MenuUI.mobile_edge_margins()` додає безпечні зони під виріз камери та
індикатор Home. Скрізь, де контент не вміщується, є видимий повзунок
(14 px) з `follow_focus`; нижні кнопки не перекривають вміст.

## Виправлення керування

- **ВІДЕО** більше не «німа»: кнопка примусово показує `FPVOverlay`
  (`set_user_visible(true)`) і циклічно змінює `Graphics.fpv_video_mode`.
  Фільтр видно навіть тоді, коли звичайний HUD-шар прихований.
- **СКИД** — кругла кнопка праворуч від лівого стіка. Якщо в апарата немає
  підвісу, показується toast `НЕМАЄ БОЄПРИПАСУ`; для дроп-дрона працює
  реальний `deploy_payload`.
- **ЗАСТ.** прибрано з верхньої панелі та з HUD.
- Стіки збільшені до 16% меншої сторони екрана, центри — 28%/72% ширини,
  низ — 64 px від краю. Верхні кнопки збільшені.
- **РЕЖИМ** показує поточний режим (`ANGLE`, `ACRO`, `SPEED`, …) і
  оновлюється кожні 0.35 с.
- У цехах прибрано `prop_pipe`, щоб труба не «вистрибувала» під час вильоту.
- Мобільне меню має збільшені таб-кнопки режимів (84 px) і кнопки місій
  (62 px), щоб ними було зручно користуватися пальцем.

## Запуск

- iOS: `StartScreen` автоматично переходить у `MobileMenu.tscn`.
- Windows/ПК: стартовий екран із відео лишається; вхід через
  **НАЛАШТУВАННЯ → МОБІЛЬНИЙ ІНТЕРФЕЙС**.
- Прямий запуск для перевірки:
  `Godot --path . res://GUI/mobile/MobileMenu.tscn`.

## QA

```powershell

$env:UI_SHOT_QA="1"
$env:UI_SHOT_SCENE="res://GUI/mobile/MobileMenu.tscn"
$env:UI_SHOT_SIZE="1280x590"
$env:UI_SHOT_PATH="$PWD\docs\mobile_menu\final\1280x590"
$env:UI_SHOT_METHODS="show_main:main,show_play:play,show_play_combat:play_combat"

# Режими / відео / кругла кнопка скиду
$env:CONTROLS_FIX_QA="1"; $env:TOUCH_CONTROLS="1"
# -> [CTRLQA] ... PASS
```

## Останні перевірки

- `CONTROLS_FIX_QA` — PASS: `mode 1→7→0→1`, `video 0→1`, overlay
  visible, drop button present.
- `DRONE_DROP_TEST` — PASS: preset 6, `ammo 4→3`, payload spawned.
- `TOUCH_STICKS_QA` — PASS: yaw/throttle/roll/pitch reach `MobileInput`;
  roll inversion `+0.8 → -0.8`.
- `INVERSION_QA` — PASS: ELRS checkbox saves, actual ELRS roll sign flips
  `+0.343 → -0.343`, touch flag saves.
- `ACTION_BIND_QA` — PASS: deploy→CH8 dispatches, setup ARM→CH10,
  conflict resolution keeps ARM and deploy separate.
- `CALIBRATION_QA` — PASS: touch wizard reaches step 14; first steps require
  real axis movement and centring.
- `CALIBRATION_ELRS_QA` — PASS: ELRS wizard records full ranges.
- `INPUT-SELFTEST` — PASS: bindings, deadband, ranges, calibration.

Мобільні значення: мертва зона **0.02** (як і на ПК), згладжування **0.10**;
ПК-версія лишається на **0.02 / 0.16**. HUD-монітор осей увімкнений лише на
телефоні (у сенсорному режимі він ховається, бо там уже є великі стіки).
