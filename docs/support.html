Підключення пульта ExpressLRS по Wi-Fi (UDP 11000) / ELRS Wi-Fi Setup

  1. На пульті відкрийте ExpressLRS Lua → WiFi Connectivity → Enable WiFi (10.0.0.1).
  2. На iPhone/iPad підключіться до Wi-Fi мережі ExpressLRS TX (пароль: expresslrs).
  3. У грі відкрийте Пульт 3D / Radio 3D і надайте дозвіл iOS Локальна мережа (Local Network).
  4. Гра автоматично приймає канали CRSF на порту UDP 11000 (Mode 2: Roll CH1, Pitch CH2, Throttle CH3, Yaw CH4, ARM CH5).

Часті питання / FAQ

  • Чи потрібен фізичний пульт? Ні — усі режими (Школа пілота, Тренування, Кампанії, Спецоперації) повністю працюють через сенсорні стіки на екрані або Bluetooth/MFi геймпади.
  • Оптимальні налаштування FPS: на старіших пристроях (iPhone 11/12/SE) рекомендується пресет LOW або MEDIUM у меню Налаштування → Графіка; динамічне масштабування автоматично тримає плавні 60 FPS.
  • Проблема чи побажання? Повідомте про помилку на сторінці підтримки нижче, вказавши модель iPhone/iPad та назву карти.
