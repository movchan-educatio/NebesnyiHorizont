# Покинутий аеропорт — QA-звіт

Фінальна перевірка карти «Аеропорт» у збірці `87d4abf`.

## Результати

- **48/48** комбінацій режимів і місій (TRAINING TAC-01..04, COMBAT TAC-01..04,
  SPECIAL 01/03/07/10) завантажуються без помилок.
- Усі обов'язкові системи `BigLevel` присутні: `CombatSystem`, `CombatHUD`,
  `CombatRange`, `Triggers`, `FPVOverlay`, `MotionBlur`, `PerformanceGovernor`,
  `RebSystem`, `FillLight`.
- 9 тіл колізії, 12 фрістайл-воріт, індикатор БЧ у всіх режимах.
- ARM знімає `freeze` — сенсорне керування працює.
- БЧ: ГРІМ-7 (камікадзе) має видиму бойову частину у FPV; екранна кнопка
  «БЧ» надсилає `activate_payload`, детонація спрацьовує (`dropped false → true`);
  у мобільному HUD/довідці літеру F замінено на «кнопка на екрані».
- Стабільний мобільний профіль: **60 FPS**, ~674 тис. примітивів, 212 draw calls
  (питки нижче показують миттєві просідання під час збереження зображень).
- Регресія `CityLevel`, `SteppeLevel`, `VillageLevel` — без помилок.
