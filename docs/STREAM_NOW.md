## Ціль $100 на реліз у App Store

Найпростіший і найнадійніший варіант — **вбудований віджет LIVE Studio «Ціль»**,
він працює з подарунками TikTok напряму (TikFinity для цього не потрібен).

### Кроки

1. LIVE Studio → **Додати джерело → Ціль**.
2. Назва цілі: **`App Store Release — $100`**
   (або українською: **`Реліз в App Store — $100`**).
3. Цільова сума: **100**.
4. Розмістіть віджет у **верхньому правому куті** — він не закриє дрон і трасу.
5. Після старту стріму перевірте, що подарунки зараховуються в прогрес.

> Якщо LIVE Studio показує ціль у «монетах» TikTok — орієнтир:
> 3000 монет ≈ $1 (залежить від регіону/курсу), тобто $100 ≈ 300 000 монет.
> Виберіть у налаштуваннях віджета зручну одиницю.

### Альтернатива — TikFinity Goal

Після успішного входу в `tikfinity.com/app/`:
**Overlays → Goal / Stream goals** → назва `App Store Release`, ціль `100`,
потім додайте URL оверлея через **Додати джерело → Посилання** у LIVE Studio.

## Якщо виникне проблема

| Симптом | Рішення |
|---|---|
| Eкран айфона чорний | Перевірте кабель і розблокуйте айфон; у LIVE Studio → Транслювати (iOS) → повторіть підключення |
| TikFinity не підключається | Завершіть Google-вхід у `tikfinity.com/app/`; якщо знову `ERR_TUNNEL_CONNECTION_FAILED` — спробуйте іншу мережу/ VPN або увійдіть через TikTok |
| Ціль не рахує подарунки | Перевірте, що стрім уже запущено, і що віджет додано в поточну сцену |
| Картинка займає не весь кадр | Виділіть джерело «Транслювати (iOS)» і розтягніть за кути до меж кадру |
