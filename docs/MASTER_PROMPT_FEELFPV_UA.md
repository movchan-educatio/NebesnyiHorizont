## 2. Що саме має бути в демо (мінімальний «ідеал»)

### Карти
- **Steppe** — окопи + ферма + вітряк; 2 бої-зони; читабельні лісосмуги.
- **Village** — ангар + вулиця + церква + двори; всі будинки з колізією.
- **Industrial** — завод + градирня + димарі + силоси + залізниця; відкриті
  вежі, чистий двір, без плаваючих стовпів.
- **Wetlands** — вода + настили + насосна + човни; м'яка вода, туман, очерет.

### Режими
- COMBAT — основний показ: 5 місій/об'єктивів, AI, HUD, перемога/поразка.
- TRAINING — кільця й вільний політ, ідеально для новачка.
- SPEED — траса з воротами, таймер, boost, respawn.
- TUTORIAL — 10 модулів, зрозумілі підказки.
- CHAOS — масова бійка для «вау»-кадру.
- TAC-01…05 — унікальні механіки, не просто «вбий усіх».

### Піхота — мінімум для показу
idle, walk, run, crouch, aim, fire, reload, hit, death. Цього достатньо,
щоб бій не виглядав як ковзання манекенів. Усе інше — P1/P2.

### Техніка — мінімум для показу
колеса/гусінь, туррель, ствол, віддача, дим, wreck. Навіть без повного
рагу, це вже читається як «справжня» техніка.

### Для анімацій і моделей
- **Mixamo** — безкоштовні humanoid-анімації, retarget на риг.
- **Rigify** (безкоштовно) або **Auto-Rig Pro** (платно) — риг у Blender.
- **AccuRig / ActorCore** — швидкий авто-риг (безкоштовний тариф).
- **Cascadeur** — фізичні анімації (безкоштовна версія).
- **glTF 2.0 exporter** — вбудований у Blender.
- **Godot AnimationTree / AnimationPlayer** — стан-машини та blend space.
- **Beehave** або **LimboAI** — behavior tree для піхоти/техніки (addon Godot).
- **NavigationAgent3D / NavigationRegion3D** — навігація.

### Для графіки
- **Poly Haven**, **ambientCG**, **Kenney**, **Quixel Megascans** (перевірити
  ліцензію) — PBR-текстури/моделі.
- **Material Maker** — процедурні PBR-матеріали.
- **Krita / GIMP** — правка текстур, decals, іконки.
- **Substance Painter/Designer** (платно) — якщо є; інакше Material Maker.
- **Meshy / Tripo** — генерація 3D (обов'язково перевірити ліцензію).
- **Scenario / Photoshop generative** — концепти/іконки (не для фінальних
  текстур без перевірки прав).

### Для звуку
- **Freesound**, **Pixabay Audio**, **Kenney Audio** — CC0/CC-BY.
- **Audacity** — чистка/лупінг.
- **ElevenLabs** — озвучка (перевірити комерційну ліцензію).
- **Godot AudioStreamPlayer3D** — 3D-звук, attenuation, crossfade.

### Для QA/профілювання
- **Godot Profiler / Monitor** — FPS, draw calls, physics, memory.
- **RenderDoc** — GPU-прохід (за потреби).
- **MSI Afterburner / GPU-Z** — температура/частоти на іншому ПК.
- **Windows Event Viewer** — збої EXE.
- **signtool** (Windows SDK) — підпис EXE/інсталятора (за бажанням).

### Плагіни Godot, які реально економлять години
- **Phantom Camera** — кінематографічна/плавна камера для шоукейсу.
- **Beehave** — behavior tree без ручного FSM.
- **LimboAI** — складніший AI, якщо Beehave мало.
- **Dialogue Manager** — брифінги/діалоги в меню.
- **Terrain3D** — тільки якщо треба новий терен; у нас уже є свій.
- **Jolt Physics** — вбудований у Godot 4.4+; перевірити сумісність.

> Для 6–8 годин не треба ставити все. Мінімум: Blender + Mixamo +
> AnimationTree + Inno Setup + QA-скрипти.

## 4. Інсталятор (Windows)

Шаблон лежить у `docs/installer/Nebesnyi_Horizont.iss`. Коротко:

1. Експортувати гру: `build\Nebesnyi_Horizont_v11.exe`.
2. Скопіювати EXE, `README.md`, `LICENSE`, `CREDITS.md` у `dist_v11\`.
3. Відкрити `Nebesnyi_Horizont.iss` у Inno Setup 6.
4. Зібрати: `"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\Nebesnyi_Horizont.iss`.
5. Отримати `installer_output\Nebesnyi_Horizont_Setup.exe`.
6. Встановити на **іншому ПК** (не там, де збирали), запустити HIGH/1440p,
   пройти меню → карту → режим, зробити скріншот/бенчмарк.
7. Перевірити: SmartScreen, відсутність відсутніх DLL, збереження налаштувань,
   деінсталяцію, ярлики, шлях `%LOCALAPPDATA%`.

Альтернатива без інсталятора: **portable ZIP** + `GRAJ.bat`; для показу
іншим гравцям краще зробити обидва варіанти.
