# iOS + ELRS WiFi: збірка через GitHub Actions

Ціль: зібрати **unsigned IPA** у GitHub Actions (macOS-раннер), підписати й
встановити на **iPhone 14** через **AltStore + LocalDevVPN** з безкоштовним
Apple ID, а пульт Radiomaster Pocket підключити **по Wi-Fi ELRS** (без
USB/Bluetooth, які Apple блокує для RC-пультів).

## 1. Що потрібно

- GitHub-акаунт (репозиторій можна зробити приватним).
- Git + Git LFS на Windows.
- iPhone 14 + Lightning-кабель.
- AltStore Classic + AltServer (Windows) + iTunes/iCloud з сайту Apple.
- Безкоштовний Apple ID.
- Pocket з ELRS **3.4+** (перевір у Lua: WiFi Connectivity → Enable WiFi).
- Інтернет для GitHub; для польоту інтернет не потрібен.

## 2. Репозиторій

Проєкт уже ініціалізовано та підключено до приватного репозиторію:

**https://github.com/movchan-educatio/NebesnyiHorizont**

Локальна гілка `main`. Оновлення:

```powershell
git add -A
git commit -m "опис змін"
git push
```

Важливо:

- `Assets/**` та великі файли зберігаються в Git LFS (`.gitattributes`).
- Ассети важать ~1.9 ГБ. GitHub Free станом на 2026 рік дає **10 GiB LFS
  storage + 10 GiB/місяць bandwidth**, тому одного пушу і кількох збірок
  вистачає. Якщо квота вичерпається — дочекайся скидання на початку місяця
  або зменш ассети.
- `dist_*`, `build`, `.godot`, `qa_shots`, EXE та відео виключені.
- Репозиторій **приватний**: ассети не публікуються.
- Перший `git push` заливає ~1.9 ГБ LFS. На повільній віддачі (ADSL/4G)
  це може тривати години; не закривай термінал і не вимикай PC, поки
  `git push` не завершиться.

## 3. Збірка

Workflow: `.github/workflows/ios.yml`.

**https://github.com/movchan-educatio/NebesnyiHorizont/actions/workflows/ios.yml**

1. Збірка стартує автоматично після пушу в `main` (або вручну:
   **Actions → Build iOS (unsigned IPA) → Run workflow**).
2. Раннер `macos-15` сам завантажує Godot 4.6.1 + iOS export templates.
3. Godot експортує Xcode-проєкт, `xcodebuild` збирає **unsigned** архів.
4. Готовий `.ipa` публікується в **Releases** під тегом `ios-build-<номер>`.

Перший запуск довший (checkout 1.9 ГБ LFS + імпорт ассетів + Xcode archive):
орієнтовно 25–45 хв. Наступні — швидші завдяки кешу Godot/templates; кеш
`.godot` не зберігається, тому імпорт повторюється.

Приватний репозиторій витрачає Actions-хвилини; macOS-раннер множиться на 10.
На GitHub Free це ~200 macOS-хвилин/місяць, тобто 4–6 збірок. Для однієї-двох
ітерацій цього достатньо.

## 4. Встановлення на iPhone 14 (AltStore)

Основний шлях — **AltStore Classic + AltServer + LocalDevVPN** (перевірено на
iPhone 14 / iOS 27). Sideloadly залишається альтернативою, але її Apple-вхід
може давати `-22406`.

1. Встанови **iTunes** і **iCloud** для Windows з сайту Apple (не з Microsoft
   Store), потім **AltServer** (altstore.io).
2. Запусти **AltServer від імені адміністратора**; підключи iPhone
   Lightning-кабелем, розблокуй і натисни **Trust This Computer**.
3. AltServer → **Install AltStore** → вибери iPhone → введи Apple ID.
4. На iPhone: **Settings → General → VPN & Device Management** → довір
   сертифікату `iPhone Developer: ...`.
5. **Settings → Privacy & Security → Developer Mode → ON**, перезавантаж.
   У **Developer Mode** натисни **Pair with AltStore** і введи код-пароль.
6. Встанови **LocalDevVPN**: AltStore запропонує **Get LocalDevVPN** —
   погодься і дозволь VPN-конфігурацію. Перевір:
   **Settings → General → VPN & Device Management → VPN → LocalDevVPN → ON**.
7. Перекинь `.ipa` на iPhone (локальний HTTP-сервер або Files) і відкрий
   **AltStore → My Apps → + → вибери IPA → Install**.
8. Якщо AltStore показує `2002/1500` — перевір, що AltServer запущений,
   iPhone і ПК в одній Wi-Fi, LocalDevVPN увімкнений, а Wi-Fi sync у iTunes
   збережений кнопкою **Apply**.

Безкоштовний підпис діє **7 днів**; AltStore/AltServer перепідписують IPA.
Платний Apple Developer ($99/рік) не потрібен. Обмеження: до 3 активних
застосунків і 10 App ID на тиждень.

Назва на домашньому екрані — **NebesnyiHorizont** (латиниця, обхід багу
AltStore з кирилицею); інтерфейс гри всередині український.

## 5. ELRS WiFi у грі

1. На пульті: `Lua → WiFi Connectivity → Enable WiFi`. Модуль створить
   `ExpressLRS TX` (пароль `expresslrs`) або підключиться до домашньої Wi-Fi.
2. iPhone → Wi-Fi → `ExpressLRS TX` (або та сама домашня мережа). Якщо iOS
   пише «No Internet Connection», вибери **Use Without Internet** / залиш
   Wi-Fi активним.
3. Запусти гру. iOS запитає **Local Network** — дозволь.
4. У HUD з’явиться `ELRS: ПОТІК`.
5. Канали (стандартний порядок AETR):
   - CH1 — roll;
   - CH2 — pitch;
   - CH3 — throttle;
   - CH4 — yaw;
   - CH5 — Arm/Disarm (перемикач);
   - CH6 — перемикання режимів польоту;
   - CH7 — режим відео.
6. На екрані також є кнопка **АРМ** — запасний варіант, якщо CH5 не налаштований.

Якщо модуль підключений до домашньої Wi-Fi, гра знаходить його по UDP-beacon.
Якщо ні — використовується `10.0.0.1` (точка доступу модуля).

Поради:

- Вимкни **Wi-Fi Assist** (Settings → Cellular) і не перемикайся на мобільну
  мережу під час польоту — інакше iOS розірве Wi-Fi з модулем.
- У EdgeTX перевір, що CH5 призначений на 2-позиційний перемикач, а CH6/CH7 —
  на 3-позиційні; інакше режими будуть перемикатися непередбачувано.
- Перший запуск після встановлення роби без польоту: переконайся, що
  `ELRS: ПОТІК`, і лише потім злітай.

### Керування сенсором (без пульта)

На iPhone/iPad у рівні автоматично з’являються два віртуальні стіки:

- **лівий** — вертикально газ (фіксується після відпускання), горизонтально
  рискання (повертається в центр);
- **правий** — тангаж/крен (повертається в центр);
- **ВВІД: СЕНСОР / ПУЛЬТ** — перемикає сенсорне керування та ELRS/фізичний
  пульт;
- **АРМ** — унизу по центру, над індикатором Home;
- верхня панель: **МЕНЮ**, **РЕЖИМ**, **ВВІД**, **СКИД**, **ЗАСТ.**,
  **РЕСЕТ**, **ВІДЕО**.

Якщо на старті рівня ELRS уже стрімить, гра запускається в режимі ПУЛЬТ;
якщо ні — в режимі СЕНСОР. Перемкнути можна кнопкою **ВВІД** у будь-який момент.
У режимі СЕНСОР центральний візуалізатор стіків ховається, щоб не дублювати
сенсорні стіки. Газ після перемикання завжди починається з нуля — піднімай
лівий стік плавно.

Для перевірки на Windows запусти гру з `TOUCH_CONTROLS=1`: миша працює як
один палець, обидва стіки можна тестувати по черзі.

### Інверсія крену

Інверсія налаштовується в старому екрані **КЕРУВАННЯ**:

1. **Головне меню → Налаштування → КЕРУВАННЯ** (або пауза → Options →
   КЕРУВАННЯ).
2. У правій колонці вгорі є картка **ELRS / СЕНСОР**:
   - **Інверсія крену (ELRS)** — для пульта Pocket;
   - **Інверсія крену (сенсор)** — для екранних стіків.
3. Увімкни потрібний пункт. Значення зберігається автоматично, перезапуск
   гри не потрібен.

Якщо крен перевернутий лише в одному режимі — перевір, який вхід активний:
**ВВІД: СЕНСОР** чи **ВВІД: ПУЛЬТ**. Інверсії для них незалежні.

### Старі екрани «КЕРУВАННЯ» та «КАЛІБРУВАННЯ»

Вони працюють на телефоні в повному вигляді, як на ПК:

1. У списку **ПРИСТРІЙ** вибери джерело:
   - **ELRS WiFi** — якщо пульт уже стрімить (у HUD `ELRS: ПОТІК`);
   - **Сенсорні стіки** — якщо пульт не підключений.
2. **КАЛІБРУВАННЯ СТІКІВ** відкриває старий покроковий майстер. У
   калібруванні кнопка **ДЖЕРЕЛО** вгорі перемикає ELRS/сенсор.
   - для **сенсора** внизу з’являються ті самі два стіки, що й у польоті;
     майстер перевіряє напрямки й повний хід;
   - для **ELRS** рухай стіки на Pocket; після завершення калібрування
     зберігається та застосовується до польоту.
3. Після калібрування з паузи гра повертається в меню паузи, а не викидає
   з рівня.

### Прив’язки кнопок

У розділі **КНОПКИ ТА ПЕРЕМИКАЧІ** натисни **Авто** біля потрібної дії
(**скид**, **застосувати БЧ**, **ресет**, **ARM**, режими, пауза тощо) і
перемкни будь-який тумблер або кнопку на Pocket у межах **CH5–CH16**. Екран
сам визначить канал і збереже прив’язку; один канал може обслуговувати лише
одну дію. Для сенсорного джерела ці дії вже винесені на екранні кнопки
**АРМ / СКИД / ЗАСТ. / РЕСЕТ / ВІДЕО / МЕНЮ**, тому їх додатково призначати
не потрібно.

Усі прив’язки, калібрування й ELRS-налаштування зберігаються у
`GameSettings.cfg` і переживають перезапуск гри.

## 6. Якщо немає даних

- Перевір ELRS firmware ≥ 3.4 (у Lua видно версію).
- iPhone дійсно підключений до `ExpressLRS TX`, а не до мобільного інтернету.
- Дозволений **Local Network** для гри (Settings → Privacy → Local Network).
  Якщо пункту немає — перевстанови гру або скинь дозволи (Settings → General →
  Transfer or Reset iPhone → Reset → Reset Location & Privacy).
- UDP 11000 не блокується; на iOS це вирішує local network permission.
- Після виходу з гри модуль має отримати `joystick_end`; якщо інша програма
  «забрала» потік — перезапусти модуль або зайди в його WebUI.
- `0xF26A` у кадрах = «немає даних»; гра такі кадри відкидає.
- Якщо HUD показує `ELRS: NO MODULE`, але iPhone в мережі модуля: відкрий
  `http://10.0.0.1/` у Safari — переконайся, що WebUI відповідає. Якщо ні,
  перезавантаж модуль (живлення/кнопка).
- Якщо модуль у домашній Wi-Fi, а гра не бачить beacon: вимкни ізоляцію
  клієнтів (AP isolation) на роутері; beacon — UDP broadcast.
- Якщо канали є, але дрон не реагує: перевір порядок каналів AETR і що CH5
  дійсно змінюється в ELRS Lua → Channels.

## 7. Обмеження

- Це **не TestFlight і не App Store**: тільки особистий підпис на 7 днів.
- Для TestFlight/App Store потрібен платний Apple Developer і підписаний
  архів; GitHub Actions може це робити, але потрібні сертифікати/профілі.
- iPhone 14 — Lightning; ELRS WiFi не потребує USB-OTG, але AltStore/AltServer
  потребує кабелю для початкового встановлення.
- iOS може переривати Wi-Fi при переході на мобільну мережу; для польоту
  тримай режим польоту/Do Not Disturb.
- Застосунок великий (~1 ГБ PCK): установка через Lightning може зайняти
  кілька хвилин, а вільне місце на iPhone має бути з запасом.
- Перша збірка в Actions може впасти через квоту LFS/Actions — подивись лог
  кроку `Checkout` або `Import project`; після скидання квоти просто
  перезапусти workflow.
