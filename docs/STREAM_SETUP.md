# Налаштування стріму FPV-симулятора (айфон → TikTok LIVE Studio)

## Схема потоку

```
[Айфон: NebesnyiHorizont, вже встановлена гра]
        |  Cast (екран телефона): USB-кабель або Wi-Fi
        v
[TikTok LIVE Studio: сцена FPV]
   ├─ Джерело 1: "Транслювати" (Cast) — картинка з айфона
   ├─ Джерело 2: "Посилання" (Link) — оверлей TikFinity
   └─ Джерело 3 (опційно): камера / мікрофон
        v
     TikTok Live
```

**Важливо:** окремий AirPlay-приймач на ПК **не потрібен**. LIVE Studio має власну
вбудовану функцію cast-у екрана айфона — в українізованому інтерфейсі вона
називається **«Транслювати»** (в англійській — *Cast source / Cast (iOS)*).

---

## 0. Стан на цьому ПК

- TikTok LIVE Studio **1.39.6**, встановлена в `C:\Program Files\TikTok LIVE Studio\`, **уже залогінена**.
- Гра на айфоні — встановлена.
- `build\ios\NebesnyiHorizont-unsigned.ipa` — резервна копія збірки (якщо знадобиться перевстановлення; див. розділ 5).
- TikFinity — веб-сервіс, потрібен ваш логін TikTok.
- Монітор: 1920×1080 фізично, масштабування Windows 150% (для стріму бажано 100–125%).

---

## 1. Підключення екрана айфона до LIVE Studio

1. У LIVE Studio виберіть сцену (наприклад, створіть нову **«FPV»**).
2. Натисніть **«Додати джерело»** → **«Транслювати»**.
3. Виберіть спосіб підключення:
   - **Кабель (рекомендовано)** — підключіть айфон USB до ПК, натисніть «Trust This Computer» на айфоні. Найстабільніший варіант, без затримок Wi-Fi.
   - **Бездротово** — ПК і айфон мають бути в одній Wi-Fi мережі (бажано 5 ГГц); далі LIVE Studio покаже інструкцію/код.
4. Дотримайтеся підказок на екрані LIVE Studio.
5. На айфоні: **Control Center → Screen Mirroring → TikTok LIVE Studio** (для бездротового варіанта).
6. Натисніть **«Додати джерело»** — у сцені з'явиться картинка з айфона.
7. Розтягніть/обріжте джерело так, щоб займати якомога більше кадру без зайвих полів.

### Поради для стабільного cast-у (з офіційної довідки TikTok)

- Увімкніть на айфоні **«Не турбувати»** — глядачі бачать весь екран, Including дзвінки й сповіщення.
- Заблокуйте орієнтацію екрана (у проєкту вже виставлено landscape: `window/handheld/orientation=4`).
- Тримайте айфон **на зарядці** — інакше iOS може гальмувати під час гри.
- Якщо є затримка або обриви — перейдіть на кабель.

---

## 2. TikFinity (алерти, подарунки, фоловери)

1. Відкрийте https://tikfinity.zerody.one/ → **Login with TikTok** (тільки ви — ваш акаунт).
2. Спочатку запустіть стрім у LIVE Studio, потім у TikFinity натисніть **Connect** — сервіс підключиться до вашого LIVE.
3. Налаштуйте алерти: подарунки, фоловери, лайки, коментарі, звуки, TTS.
4. Скопіюйте URL оверлея з https://tikfinity.zerody.one/tiktok/obsoverlays.
5. У LIVE Studio: **Додати джерело → Посилання (Link)** → вставте URL.
6. Перевірте, що оверлей видно в прев'ю **до** початку стріму.

OBS/Streamlabs не потрібні — TikFinity офіційно підтримує LIVE Studio через Link Source.

---

## 3. Налаштування зображення і продуктивності

- У LIVE Studio: **1920×1080, 30 fps** (60 fps — тільки якщо ПК/stable cast витримує), бітрейт **2500–4000 kbps**.
- Windows-масштабування: зараз 150% → для різкішої картинки бажано 100–125%:
  `Правий клік по робочому столу → Display settings → Scale and layout`.
- Не згортайте LIVE Studio під час ефіру.
- Закрийте зайві програми, особливо ті, що активно використовують GPU/CPU.
- Перевірте звук і мікрофон у розділі попереднього перегляду перед ефіром.

---

## 4. Чеклист перед ефіром

- [ ] Гра запущена на айфоні, «Не турбувати» увімкнено, айфон на зарядці, орієнтація заблокована.
- [ ] Айфон підключено (кабель або Wi-Fi) і джерело «Транслювати» показує гру в прев'ю LIVE Studio.
- [ ] Джерело «Посилання» з TikFinity додано й видно в прев'ю.
- [ ] TikFinity підключено до поточного LIVE.
- [ ] Звук/мікрофон перевірено.
- [ ] Зайві вікна й сповіщення на ПК закрито.

---

## 5. Якщо знадобиться перевстановлення гри

`build\ios\NebesnyiHorizont-unsigned.ipa` — **unsigned**, тому встановлюється тільки через sideload:

- **Sideloadly** (безкоштовно, Windows): https://sideloadly.io/ — підключіть айфон USB, «Trust This Computer», перетягніть IPA, введіть Apple ID, Start. Безкоштовний акаунт → профіль на 7 днів, потім перепідпис.
- **Apple Developer** ($99/рік) — профіль на 1 рік, найстабільніше.
- **AltStore Classic 2.3b1** — у 2026 вміє встановлювати IPA без ПК: https://altstore.io/

## 6. Вирішення проблем

| Симптом | Причина / рішення |
|---|---|
| Джерело «Транслювати» показує чорне | Айфон не підключено / не підтверджено «Trust This Computer» |
| Затримка або обриви картинки | Використайте USB-кабель замість Wi-Fi; наблизьте роутер; вимкніть «Не турбувати» не потрібно, а от зайві фонові застосунки на айфоні — варто |
| Айфон не з'являється у списку | Різні Wi-Fi мережі; увімкніть 5 ГГц; перевірте брандмауер Windows |
| Гальмування у стрімі | 30 fps / 2500 kbps, закрийте зайві програми, тримайте айфон на зарядці |
| Алерти TikFinity не працюють | Стрім ще не запущено або TikFinity не підключено до LIVE |
| Картинка розмита | Зменшіть масштабування Windows до 100–125% |
